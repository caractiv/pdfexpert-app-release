## Install / 安装

Open **Releases** and choose the APK for your device:

| APK | Device |
| --- | --- |
| arm64-v8a | Most current Android phones / 大多数现代 Android 手机 |
| armeabi-v7a | Older 32-bit ARM devices / 较早的 32 位 ARM 设备 |
| x86_64 | Compatible Intel/AMD Android devices and emulators / 兼容的 x86_64 设备与模拟器 |

Android 7.0 or later is required. Download **SHA256SUMS.txt** from the same release to verify the file. Public APK filenames omit parentheses from our internal build filenames; the signed APK bytes are identical.

Use Google Play to update a Google Play installation, and these releases to update a standalone APK installation. Store and standalone APKs can use different signing certificates; if Android refuses an update, back up your documents before changing your installation. Never uninstall an app containing important files without a backup.
